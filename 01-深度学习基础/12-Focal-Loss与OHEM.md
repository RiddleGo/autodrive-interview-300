# 第 12 题：Focal Loss 与 OHEM

## 题目

什么是 Focal Loss？解决了什么问题？与 OHEM 的区别？

---

## 一、One-Stage 检测中的类别不平衡

在密集预测（如 RetinaNet、早期 YOLO）中，**背景格点/anchor 数量远多于前景**（常为 10^3～10^4 : 1）。若用普通交叉熵，每个样本等权，loss 会被大量“易分类背景”主导，模型倾向全预测背景，前景学不好。

**目标**：降低**易分类样本**（尤其是易分类负样本）对 loss 的贡献，让模型更关注**难分类样本**和**正样本**。

---

## 二、Focal Loss 是什么？

**Focal Loss** 在标准交叉熵前加一个**调制因子** $(1-p_t)^\gamma$，使“预测越自信（$p_t$ 越大）”的样本权重越小。

设 $p_t$ 为真实类别的预测概率（二分类时正类概率为 $p$，负类为 $1-p$，$p_t$ 取对应那个），则：
$$\mathrm{FL}(p_t) = -\alpha_t (1-p_t)^\gamma \log(p_t)$$

- **$\gamma$（focusing parameter）**：通常取 2。$p_t \to 1$ 时 $(1-p_t)^\gamma \to 0$，易分类样本 loss 被压得很低；$p_t$ 小（难分类）时权重大。
- **$\alpha_t$**：类别权重，用于平衡正负样本数量（如正样本少则正类 $\alpha$ 略大）。

**效果**：易分类的负样本 $p_t$ 接近 1，loss 几乎为 0；难分类的负样本和正样本 $p_t$ 小，保留大部分 loss，从而**自动聚焦难样本**，无需显式困难样本挖掘。

---

## 三、Focal Loss 解决了什么问题？

- **问题**：正负样本极不均衡 + 易分类负样本数量巨大，导致 CE loss 被它们主导。
- **解决**：用 $(1-p_t)^\gamma$ 降权易分类样本，使 loss 主要由难分类样本和正样本贡献，**隐式地做了困难样本挖掘**，且可导、端到端训练。
- **典型应用**：RetinaNet 用 Focal Loss 做 one-stage 检测，在不加 RPN 的情况下达到与 two-stage 相当的精度。

---

## 四、OHEM 是什么？

**OHEM（Online Hard Example Mining）**：每次前向时，对**所有**样本算 loss，只保留 **loss 最大**的一部分（如 top 50%）参与反向传播，其余梯度置 0。

- **“Hard”**：loss 大表示预测错得厉害或难分类，即困难样本。
- **在线**：每个 batch 动态选困难样本，不需要离线预选。

**作用**：让训练更关注难样本，缓解简单负样本主导。但实现上需要“前向 → 按 loss 排序 → 只对部分样本回传”，工程略麻烦，且可能忽略一部分有用样本。

---

## 五、Focal Loss 与 OHEM 的区别

| 维度 | Focal Loss | OHEM |
|------|------------|------|
| **方式** | 改 loss 形式，用 $(1-p_t)^\gamma$ 降权易样本 | 不改 loss，只取 loss 大的样本回传 |
| **是否可导** | 处处可导，正常反向传播 | 需对“选中的样本”回传，未选中的梯度为 0（等价于权重 0） |
| **软/硬** | 软：易样本权重大幅减小但非 0 | 硬：只保留一部分样本，其余完全丢弃 |
| **实现** | 改一行 loss，简单 | 需排序、mask 梯度，稍复杂 |
| **效果** | 平滑地聚焦难样本，稳定 | 更激进地只训难样本，可能过拟合难样本 |

**总结**：Focal 是“软”的困难样本加权，OHEM 是“硬”的困难样本筛选；Focal 更易实现、更平滑，目前 one-stage 检测里 Focal 更常用；OHEM 在 two-stage（如 Fast R-CNN）里曾常用做困难负样本挖掘。

---

## 六、小结与面试要点

**小结**：Focal Loss 用 $(1-p_t)^\gamma$ 降低易分类样本权重，解决正负与难易不均衡；OHEM 只对 loss 大的样本回传，做困难样本挖掘；Focal 更软、可导、实现简单，OHEM 更硬、实现稍复杂。

**面试要点**：

- Focal 公式：$-\alpha_t(1-p_t)^\gamma\log(p_t)$；$\gamma=2$ 常用，$p_t$ 大则权小。
- 解决的问题：易分类负样本过多导致 CE 被主导；Focal 自动聚焦难样本。
- 与 OHEM：Focal 改 loss 软降权，OHEM 硬选样本；Focal 更常用、更易实现。

---

## 记忆要点

1. **Focal**：$(1-p_t)^\gamma$ 降权易样本，$p_t$ 大→权小。
2. **问题**：正负与难易不均衡，易分类负样本主导 CE。
3. **OHEM**：只对 loss 大的样本回传，硬挖掘。
4. **区别**：Focal 软、可导；OHEM 硬、需选样本。
