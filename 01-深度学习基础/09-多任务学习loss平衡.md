# 第 9 题：多任务学习中 loss 不平衡的处理

## 题目

多任务学习中如何处理 loss 不平衡问题？有哪些自动平衡策略？

---

## 一、为什么会有 loss 不平衡？

多任务学习（MTL）里，一个模型同时优化多个 loss（如分类 + 回归 + 分割），各 loss 的**量纲、数值尺度、收敛速度**往往不同：

- 例如：分类 cross-entropy 在 0.x～2，回归 L1/L2 可能几十、几百；或某任务梯度大、某任务梯度小。
- 若简单把多个 loss **直接相加**，尺度大的任务会主导梯度，其他任务学不好，甚至被“压制”。

所以需要**平衡**各 loss 的贡献，让各任务都能有效学习。

---

## 二、手动与半自动平衡

**1. 手动权重**  
$\mathcal{L} = \sum_i w_i \mathcal{L}_i$，根据验证集或经验调 $w_i$。简单但费时，且不同阶段最优权重可能不同。

**2. 损失归一化**  
对每个 $\mathcal{L}_i$ 除以其初始值或滑动平均，使各 loss 量级接近 1 再相加。减轻尺度差异，但初始值或均值的选择会影响后续。

**3. 梯度归一化**  
先分别算各任务梯度，再对每个任务的梯度做缩放（如除以其范数），使各任务梯度范数相当，再相加更新。这样平衡的是“梯度贡献”而不是 loss 数值。

---

## 三、自动平衡策略（面试重点）

**1. Uncertainty Weighting（多任务不确定性）**  
论文 *Multi-Task Learning Using Uncertainty to Weigh Losses*：把每个任务的 loss 视为高斯似然，引入可学习的**任务相关噪声参数** $\sigma_i$，总 loss 为：
$$\mathcal{L} = \sum_i \frac{1}{2\sigma_i^2} \mathcal{L}_i + \log \sigma_i$$
$\sigma_i$ 大表示该任务不确定性大，自动降低其权重；$\sigma_i$ 小则权重大。实现简单：多几个可学习标量，和主网络一起训练。

**2. GradNorm**  
根据各任务 loss 的**相对下降速度**动态调整权重：若某任务 loss 降得慢，增大其权重；若降得快，减小权重，使各任务训练速度接近。通过对各任务梯度范数做归一化并加辅助 loss 实现。

**3. PCGrad / CAGrad**  
考虑**梯度冲突**：若任务 A 与任务 B 的梯度方向相反，简单相加会相互抵消。PCGrad 在更新前对每个任务的梯度做“投影”：把任务 A 的梯度投影到与任务 B 梯度正交的方向（或类似处理），再求和，减轻冲突。CAGrad 是后续改进，在共同梯度方向与冲突之间做权衡。

**4. DWA（Dynamic Weight Average）**  
根据各任务 **loss 下降率** 的比值动态设权重：近期下降快的任务权重大，下降慢的权重小，使各任务进步速度相对均衡。

**5. 其他**  
如 Pareto MTL（多目标优化）、MGDA 等，在需要严格多目标或理论保证时使用；工程里最常用的是 **Uncertainty Weighting** 和 **手动/梯度归一化**。

---

## 四、自动驾驶场景中的典型用法

- 感知多任务：检测 + 分割 + 深度等，常用 **Uncertainty Weighting** 或**手动权重 + 验证集调参**。
- 有明确主次任务时：主任务权重固定为 1，次要任务用小权重或 Uncertainty 自动调。
- 若发现某任务梯度远大于其他：可先做**梯度裁剪/归一化**再平衡，避免单任务梯度爆炸。

---

## 五、小结与面试要点

**小结**：多任务 loss 不平衡来自量纲与梯度尺度差异；可通过手动权重、loss/梯度归一化、Uncertainty Weighting、GradNorm、PCGrad 等平衡；工程上 Uncertainty Weighting 和梯度归一化最常用。

**面试要点**：

- 问题本质：各 loss 尺度与梯度尺度不一致，简单相加会偏向大尺度任务。
- Uncertainty：$\mathcal{L} = \sum_i \frac{1}{2\sigma_i^2}\mathcal{L}_i + \log\sigma_i$，$\sigma_i$ 可学习，自动降权高不确定性任务。
- PCGrad：解决梯度冲突，对梯度做投影再相加。
- 实用：先试 Uncertainty 或手动权重；有冲突再考虑 PCGrad/GradNorm。

---

## 记忆要点

1. **不平衡原因**：loss 量纲与梯度尺度不同，直接相加会偏向某任务。
2. **Uncertainty**：可学习 $\sigma_i$，$1/\sigma_i^2$ 作权重，实现简单。
3. **GradNorm / DWA**：按训练速度或梯度范数动态调权。
4. **PCGrad**：缓解梯度方向冲突，投影后再加。
