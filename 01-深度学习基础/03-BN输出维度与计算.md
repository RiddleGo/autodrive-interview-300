# 第 3 题：BN 层在 NCHW 下的输出维度与计算过程

## 题目

给定 NCHW 输入，BN 层的输出维度是什么？计算过程如何？

---

## 一、NCHW 与 BN 的维度约定

- **NCHW**：Batch（N）× Channel（C）× Height（H）× Width（W）。
- BN 对**每个通道**独立做标准化：在同一通道上，对 **N×H×W** 个元素算均值和方差，因此**不改变张量形状**。

**结论**：输入形状为 $(N,\,C,\,H,\,W)$ 时，BN 的输出形状仍为 $(N,\,C,\,H,\,W)$。

---

## 二、计算过程（按通道）

对通道 $c$（$c=0,\ldots,C-1$）：

1. **取该通道所有元素**：形状为 $(N,\,H,\,W)$，共 $N \times H \times W$ 个数。
2. **算均值与方差**：
   - $\mu_c = \frac{1}{NHW}\sum_{n,h,w} x_{n,c,h,w}$
   - $\sigma_c^2 = \frac{1}{NHW}\sum_{n,h,w} (x_{n,c,h,w} - \mu_c)^2$
3. **标准化**：$\hat{x}_{n,c,h,w} = \frac{x_{n,c,h,w} - \mu_c}{\sqrt{\sigma_c^2 + \epsilon}}$
4. **仿射**：$y_{n,c,h,w} = \gamma_c \,\hat{x}_{n,c,h,w} + \beta_c$

对每个 $c$ 重复，$\gamma_c$、$\beta_c$ 为该通道的可学习参数。训练时还会用当前 batch 的 $\mu_c$、$\sigma_c^2$ 更新 running mean 和 running variance。

---

## 三、维度与参数量小结

| 项目       | 说明 |
|------------|------|
| 输入/输出形状 | $(N,\,C,\,H,\,W) \to (N,\,C,\,H,\,W)$，不变 |
| 统计维度   | 在 N、H、W 上做统计，即每个通道 $NHW$ 个元素 |
| 可学习参数 | $\gamma,\,\beta$ 各 $C$ 个，共 $2C$ |
| Running    | running mean、running var 各 $C$ 个 |

面试常问：“为什么是 NCHW 而不是 NHWC？”——在 C 维做 BN 时，NCHW 下同一通道在内存中连续，实现简单、缓存友好；NHWC 也可做，但通常按 C 维索引。

---

## 四、小结与面试要点

**小结**：给定 NCHW 输入，BN 输出维度与输入相同 $(N,C,H,W)$。对每个通道在 N×H×W 上算均值、方差，做标准化后再用该通道的 $\gamma$、$\beta$ 仿射。

**面试要点**：

- 输出维度 = 输入维度，形状不变。
- 统计在哪些维上做？在 N、H、W 上（即每个通道的 $NHW$ 个值）。
- 可学习参数：$\gamma$、$\beta$，各 $C$ 个。

---

## 记忆要点

1. 输入/输出形状均为 $(N,\,C,\,H,\,W)$。
2. 每个通道独立：在 N、H、W 上算 $\mu_c$、$\sigma_c^2$，再标准化 + $\gamma_c$、$\beta_c$。
3. 参数量：可学习 $2C$；running 状态 $2C$。
