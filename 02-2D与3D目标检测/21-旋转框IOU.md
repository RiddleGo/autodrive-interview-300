# 第 21 题：旋转框（Rotated BBox）的 IoU 计算

## 题目

旋转框检测（Rotated BBox）的 IoU 计算如何实现？

---

## 一、旋转框的表示

旋转框（Rotated BBox）除了中心与宽高，还有**旋转角度** $\theta$，常见表示：
- **(cx, cy, w, h, θ)**：中心、宽高、与 x 轴夹角（或与长边夹角）。
- **四个顶点**：$(x_i, y_i)_{i=1..4}$，按顺序表示四边形。

两旋转框的 **IoU = 交集面积 / 并集面积**；难点在于**交集是多边形**，需要求两凸多边形的交面积。

---

## 二、思路一：多边形相交求面积

1. 把两个旋转框各自用 **4 个顶点**表示（由中心+半宽半高+角度可算得）。
2. 求两**凸四边形**的**相交多边形**：可用 Sutherland-Hodgman 裁剪、或一般多边形相交算法（如 Shapely 库的 `intersection`），得到相交多边形的顶点。
3. **相交多边形面积**：用**鞋带公式（Shoelace）**：按顶点顺序 $(x_i,y_i)$，面积 $S = \frac{1}{2}|\sum_i (x_i y_{i+1} - x_{i+1} y_i)|$（首尾相接）。
4. **并集面积** = 面积 A + 面积 B - 交集面积。
5. **IoU** = 交集 / 并集；若无交集则为 0。

---

## 三、思路二：旋转到轴对齐再算（简化情形）

若两框**角度相同**，可把坐标系旋转 $-\theta$，两框都变成轴对齐矩形，用轴对齐 IoU 公式即可。  
若角度不同，一般仍需按多边形相交来算。

---

## 四、实现注意点

- **数值稳定**：交点多、共线、退化多边形时要判断，面积接近 0 时 IoU 置 0。
- **顶点顺序**：同一旋转方向（如逆时针），鞋带公式符号一致。
- **库**：Python 可用 **Shapely**（`Polygon.intersection`、`area`）；C++ 可手写多边形裁剪或用几何库。
- **加速**：大量旋转框 IoU 时可用 CUDA、或近似方法（如将旋转框采样成点用近似 IoU）。

---

## 五、小结与面试要点

**小结**：旋转框 IoU = 交面积/并面积；交面积为两四边形相交多边形，用多边形相交算法 + 鞋带公式求面积；并 = 面积A + 面积B - 交。

**面试要点**：
- 表示：(cx, cy, w, h, θ) 或四顶点。
- 步骤：四顶点 → 求相交多边形 → 鞋带公式求交面积 → 并 = A+B-交 → IoU。
- 库：Shapely；C++ 手写裁剪或几何库。

---

## 记忆要点

1. 旋转框 = 中心 + 宽高 + 角度 或 四顶点。
2. IoU = 交/并；交 = 两凸四边形相交多边形面积。
3. 交面积：多边形相交算法 + 鞋带公式。
4. 并 = 面积A + 面积B - 交。
