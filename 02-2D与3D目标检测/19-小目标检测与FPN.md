# 第 19 题：小目标检测难点与多尺度特征融合（FPN）

## 题目

小目标检测的难点及解决方案？多尺度特征融合（FPN）原理？

---

## 一、小目标检测的难点

1. **分辨率低**：小目标在图像里只占很少像素，下采样后特征图上可能只剩 1～2 个点，**语义信息少、易丢失**。
2. ** backbone 下采样**：为扩大感受野、降计算量，网络会多次 stride=2，小目标在高层特征图上的响应很弱甚至消失。
3. **正样本少**：同一张图里小目标数量有限，anchor 或正样本格点少，**正负样本更不均衡**，学习不充分。
4. **定位敏感**：小目标框小，几个像素的偏差就会导致 IoU 骤降，**回归要求高**。
5. **遮挡与模糊**：小目标易被遮挡、运动模糊，外观不稳定。

---

## 二、FPN（Feature Pyramid Networks）在做什么？

**思想**：不同层级的特征图对应**不同尺度**的语义与分辨率：浅层高分辨率、细节多、适合小目标；深层低分辨率、语义强、适合大目标。FPN 通过**自顶向下路径 + 横向连接**，把深层的语义传到浅层，在**多层级**上做预测或提供特征，形成“多尺度特征金字塔”。

**结构**：
- **自底向上**：backbone 正常前向，得到多级特征（如 C2, C3, C4, C5），stride 依次增大。
- **自顶向下**：从最深层（如 C5）开始，上采样（如 2×）后与**上一级**（如 C4）经 1×1 对齐通道后的特征**相加**，得到融合后的 P4；再对 P4 上采样与 C3 相加得 P3，以此类推，得到 P2～P5。
- **横向连接**：每一级 backbone 特征先经 1×1 卷积把通道数统一（如 256），再与上采样后的顶层特征相加，避免通道与语义不匹配。

**效果**：每一层 P 都既有**高分辨率细节**（来自浅层）又有**强语义**（来自深层），小目标在 P2/P3 上检测、大目标在 P4/P5 上检测，**多尺度目标都能在合适层级得到表达**。

---

## 三、小目标常用解决方案小结

| 手段 | 说明 |
|------|------|
| **FPN / 多尺度预测** | 在多个层级上做检测，小目标用高分辨率层（P2/P3）。 |
| **增大输入分辨率** | 小目标占更多像素，但计算量上升。 |
| **数据增强** |  mosaic、小目标过采样、复制粘贴小目标，增加正样本。 |
| **更密的 anchor / 更小 stride** | 让小目标有对应 anchor；或使用 anchor-free + 高分辨率特征。 |
| **注意力与上下文** | 用上下文或注意力增强小目标特征。 |
| **损失与正样本** | 小目标适当提高权重、改进正样本分配（如 TAL）。 |

---

## 四、小结与面试要点

**小结**：小目标难在分辨率低、易在下采样中丢失、正样本少、定位敏感；FPN 通过自顶向下 + 横向连接构造多尺度金字塔，让各尺度在合适层级被检测；再配合输入分辨率、数据增强、anchor/stride 设计等。

**面试要点**：
- 小目标难点：分辨率低、下采样丢失、正样本少、定位敏感。
- FPN：自顶向下上采样 + 与 backbone 层相加，多尺度特征、多层级预测。
- 方案：FPN、大输入、mosaic、小目标过采样、高分辨率层预测。

---

## 记忆要点

1. 小目标：像素少、易丢失、正样本少、定位要求高。
2. FPN：自顶向下 + 横向相加，P2～P5 多尺度。
3. 小目标用 P2/P3 高分辨率层。
4. 配合：大输入、数据增强、anchor/stride、损失权重。
