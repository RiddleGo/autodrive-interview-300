# 第 244 题：LCS 与 LIS

## 题目

最长公共子序列（LCS）与最长上升子序列（LIS）的 DP 定义与转移？复杂度与优化思路？

---

## 一、LCS（最长公共子序列）

**问题**：两个序列 A、B，求最长公共子序列（不要求连续）。  
**状态**：`dp[i][j]` = A[0..i-1] 与 B[0..j-1] 的 LCS 长度。  
**转移**：若 A[i-1]==B[j-1]，则 `dp[i][j] = dp[i-1][j-1]+1`；否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。  
**边界**：`dp[0][*]=dp[*][0]=0`。  
**复杂度**：时间 **O(nm)**，空间可滚动成 O(min(n,m))。  
**还原方案**：从 (n,m) 反推，根据 dp 值判断是从 (i-1,j-1)、(i-1,j) 还是 (i,j-1) 转移。

---

## 二、LIS（最长上升子序列）

**问题**：序列 A，求最长严格上升子序列长度。  
**O(n²) 做法**：`dp[i]` = 以 A[i] 结尾的 LIS 长度；`dp[i] = 1 + max{ dp[j] : j<i 且 A[j]<A[i] }`；答案为 max dp[i]。  
**O(n log n) 做法**：维护**单调数组** d，d[len] 表示长度为 len 的上升子序列的**最小末尾**；对每个 A[i]，在 d 中二分找第一个 ≥A[i] 的位置并更新，同时可更新 len；最终 len 即为 LIS 长度。  
**还原方案**：O(n²) 时记录前驱；O(n log n) 时可在二分时记录位置再反推。

---

## 三、小结

**LCS**：二维 DP，按是否相等分两种情况转移。  
**LIS**：一维 DP 可 O(n²)；二分+单调数组 O(n log n)。  
面试可答：LCS 的 dp[i][j] 由 A[i-1] 与 B[j-1] 是否相等分两种转移；LIS 可 dp[i] 以 i 结尾 O(n²)，或二分维护最小末尾序列 O(n log n)。

---

## 小结与面试要点

**小结**：LCS 二维 DP 双串；LIS 一维 DP 或二分贪心。

**面试要点**：能写 LCS 转移方程；能说明 LIS 的 O(n²) 与 O(n log n) 思路。

---

## 记忆要点

1. **LCS**：dp[i][j]=LCS(A[0..i-1],B[0..j-1])；相等+1，否则 max(左,上)。  
2. **LIS O(n²)**：dp[i]=以 A[i] 结尾的 LIS；从前面的更小值转移。  
3. **LIS O(n log n)**：维护最小末尾数组 d，二分更新。
