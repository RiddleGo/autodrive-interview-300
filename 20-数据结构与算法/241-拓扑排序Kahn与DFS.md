# 第 241 题：拓扑排序 Kahn 与 DFS

## 题目

什么是拓扑排序？Kahn 算法（BFS）与 DFS 实现拓扑排序的思路？如何判环？

---

## 一、拓扑排序

**含义**：有向无环图（DAG）的顶点的一种**线性序列**，使得对每条边 (u,v)，u 都排在 v 前面；常用于依赖关系、编译顺序等。  
**存在性**：仅 **DAG** 有拓扑序；有环则无拓扑序。

---

## 二、Kahn 算法（BFS）

**思路**：**入度为 0** 的顶点没有前驱，可排在最前；每次取一个入度为 0 的点加入结果，并**删去其出边**（将邻接点入度减 1），再取新的入度为 0 的点；重复直到无点可选。  
**实现**：先算所有点**入度**；队列存当前入度为 0 的点；出队即加入拓扑序，对其邻接点入度减 1，若减为 0 则入队。  
**判环**：若**结果序列长度 < n**，说明存在环（环上点入度永不为 0）。  
**复杂度**：O(n + m)。

---

## 三、DFS 实现

**思路**：对图做 DFS，**回溯时**将当前点加入结果（或压栈），最后**逆序**即为拓扑序—保证 u 在 v 前访问则 u 在 v 后入栈、逆序后 u 在 v 前。  
**实现**：需标记访问状态；若发现**回边**（指向已访问且仍在栈中的点）则存在环；用三色标记（未访问/访问中/已结束）可同时判环与收集拓扑序。  
**判环**：DFS 中若到达“访问中”的节点则有环。

面试可答：拓扑排序是 DAG 的线性序使边总从前指向后；Kahn 用入度 0 的队列、删边减入度；DFS 回溯时入栈再逆序；结果长度小于 n 或 DFS 遇回边则有环。

---

## 小结与面试要点

**小结**：Kahn 入度 0 + BFS；DFS 回溯入栈逆序；二者都可判环（结果长度或回边）。

**面试要点**：能手写 Kahn 或 DFS 拓扑排序，并说明如何判环。

---

## 记忆要点

1. **Kahn**：入度 0 入队，出队加入序、邻接点入度−1；O(n+m)。  
2. **DFS**：回溯时入栈，逆序即拓扑序；三色可判环。  
3. **判环**：Kahn 结果长度<n；DFS 遇“访问中”节点。
