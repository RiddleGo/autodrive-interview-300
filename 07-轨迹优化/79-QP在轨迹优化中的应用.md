# 第 79 题：QP 在轨迹优化中的应用

## 题目

二次规划（QP）在轨迹优化中如何建模？目标与约束通常怎样写？

---

## 一、为什么用 QP

**形式**：QP = 最小化二次目标 + 线性等式/不等式约束，即  
$$\min_x \ \frac{1}{2} x^T Q x + c^T x \quad \text{s.t.} \ Ax=b,\ Gx\le h.$$  
**优点**：**凸 QP**（Q≥0）有唯一全局解（若存在）、求解器成熟（OSQP、qpOASES、MOSEK 等）、实时可行；轨迹的**jerk/加速度平方和**是二次、很多边界与动力学约束在参数化下可写成线性，故 QP 是轨迹层最常用的优化形式。

---

## 二、决策变量与参数化

**决策变量 x**：多为**轨迹参数**，例如：  
- **纵向/横向多项式系数**：如每段五次多项式的 (a0,…,a5)，纵向 s(t) 与横向 d(s) 的系数拼成 x。  
- **样条控制点**：B 样条或贝塞尔控制点。  
- **离散点**：路径上若干点的位置/速度，再通过插值或动力学约束关联。

**线性参数化**：若轨迹的**位置、速度、加速度**都是 x 的**线性函数**（多项式、样条在系数/控制点上线性），则“最小化加速度平方和”= x^T Q x + 常数，约束“速度在 [v_min, v_max]”= 线性不等式，整体是 QP。

---

## 三、目标与约束的常见写法

**目标**：  
- **Jerk 最小化**：$\int \dddot{s}^2 dt$ 或离散化 $\sum (\text{jerk}_i)^2$ → 在多项式系数下为 x^T Q x。  
- **加速度最小化**：同上，二次。  
- **偏离参考**：$(d - d_{ref})^2$、$(s - s_{ref})^2$ 对离散点或系数求和 → 二次。  
- **时间**：若时间 T 也作为变量且只出现线性，可与二次目标组合（有的写成带权和的单目标）。

**约束**：  
- **边界**：$d_{min} \le d(s) \le d_{max}$、$v_{min} \le \dot{s} \le v_{max}$ → 在采样点或段端点写为 Gx ≤ h。  
- **连续性**：段与段之间位置、速度、加速度相等 → Ax = b。  
- **障碍物**：在 Frenet 下常把障碍投影为 s-d 或 s-t 的带状/多边形，轨迹点需在可行侧 → 线性不等式；或“与障碍距离 ≥ 某值”在局部线性化后为线性。  
- **曲率/动力学**：曲率 κ 与横向加速度等，在 d(s)、s(t) 参数化下可写为系数或控制点的函数；**线性化**后为线性约束，或近似为二次约束（QCQP 子集仍可解）。

**求解**：调用 OSQP、qpOASES 等，得到最优 x，再还原为轨迹 s(t)、d(s) 及 (x,y,θ) 等供控制使用。

面试常问：“轨迹 QP 的 x 是什么？”——多为多项式系数或样条控制点；目标常为 jerk/加速度/偏离参考的二次项；约束为边界、连续性、障碍的线性（或线性化）形式。

---

## 小结与面试要点

**小结**：轨迹 QP 的决策变量常为多项式系数或控制点；目标为 jerk/加速度/偏离的二次型；约束为边界、连续性、障碍的线性（或线性化）；线性参数化使问题保持 QP 形式，便于实时求解。

**面试要点**：能写出 QP 标准形；说明 x、Q、约束在轨迹中的对应；会举一两个目标与约束例子。

---

## 记忆要点

1. **QP**：min 二次 + 线性等式/不等式；凸 QP 高效可解。  
2. **x**：多项式系数或样条控制点。  
3. **目标**：jerk/加速度平方和、偏离参考的二次。  
4. **约束**：边界、连续性、障碍（线性或线性化）。
