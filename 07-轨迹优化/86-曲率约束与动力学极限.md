# 第 86 题：曲率约束与动力学极限

## 题目

轨迹优化中曲率约束如何体现？与车辆动力学极限（速度、加速度、转弯）有何关系？

---

## 一、曲率约束的必要性

**几何**：曲率 κ 表示路径弯曲程度；κ 过大则转弯过急，车辆**无法按路径行驶**（最小转弯半径限制）。  
**动力学**：横向加速度 $a_y = v^2 \kappa$（或近似）；κ 或 v 过大会导致 $a_y$ 超限（轮胎侧向力、舒适性）。因此轨迹必须满足 **κ ≤ κ_max**，且与速度 v 联合考虑 $v^2 \kappa \le a_{y,max}$。

---

## 二、曲率与动力学极限

**最小转弯半径**：$R_{min} = 1/\kappa_{max}$，由车辆最大转向角与轴距等决定；路径曲率需满足 $\kappa \le \kappa_{max}$。  
**横向加速度**：$a_y = v^2 \kappa$；给定 $a_{y,max}$（轮胎或舒适限制），有 $\kappa \le a_{y,max}/v^2$，即**高速时曲率上限更严**。  
**联合约束**：实际约束为 $\kappa \le \min(\kappa_{max},\, a_{y,max}/v^2)$；在轨迹上每点 (s, v) 或 (t, s, v) 均需满足，形成**曲率-速度**耦合约束。

---

## 三、在优化中的处理

**参数化**：轨迹用 d(s)、s(t) 或 (x(s), y(s)) 表示时，曲率 κ 是**位置与导数**的函数（如 $\kappa = \frac{d''}{(1+d'^2)^{3/2}}$ 在 Frenet 下，或笛卡尔下 $\kappa = \frac{\dot{x}\ddot{y}-\dot{y}\ddot{x}}{(\dot{x}^2+\dot{y}^2)^{3/2}}$），对多项式系数或控制点而言多为**非线性**。  
**线性化**：在参考轨迹附近将 κ 对决策变量**一阶展开**，得到线性不等式，纳入 QP；每轮求解后更新参考再线性化，迭代（如 SQP）。  
**采样/离散**：在路径上取若干点，每点显式约束 $\kappa_i \le \kappa_{max}$ 或 $v_i^2 \kappa_i \le a_{y,max}$；κ_i 用系数表示时可能为二次（如分子二次、分母正），可近似为线性或放缩成线性。  
**速度规划配合**：先规划几何路径的 κ(s)，再在速度规划中保证 $v(s)^2 \kappa(s) \le a_{y,max}$，即**限速曲线**；或联合优化 s(t) 与 d(s) 时把曲率-速度约束一并加入。

面试常问：“为什么曲率约束常做成非线性？”——κ 是位置二阶导与一阶导的组合，对轨迹参数（系数）是非线性的；工程上通过线性化、离散采样或分层（先路径后速度）处理。

---

## 小结与面试要点

**小结**：曲率约束来自最小转弯半径与横向加速度限制；κ 与 v 耦合（κ ≤ a_y_max/v²）；在优化中多为非线性，需线性化、离散或分层处理。

**面试要点**：能写出曲率与横向加速度关系；说明为何与速度耦合；知道在 QP 中处理的常见做法（线性化、离散、分层）。

---

## 记忆要点

1. **曲率**：κ ≤ κ_max（转弯半径）；κ ≤ a_y_max/v²（横向加速度）。  
2. **耦合**：高速时曲率上限更严。  
3. **非线性**：κ 对轨迹参数非线性；线性化或离散处理。  
4. **实现**：分层（路径+速度）或联合优化+线性化。
