# 第 80 题：EM Planner 中 DP 与 QP 分工

## 题目

EM Planner（或类似分层规划器）中，DP 与 QP 分别负责什么？为何要这样分工？

---

## 一、整体分层思路

**EM**：常指“Egress-Maneuver”或“多阶段决策+优化”的分层结构：上层做**离散决策/粗规划**（选车道、选轨迹族、在 ST 图上选“通道”），下层做**连续轨迹优化**（在选定通道内求平滑、满足约束的轨迹）。  
**DP**：多用于**上层**——在离散空间（如 ST 网格、车道片段、轨迹簇）上做多阶段决策，考虑障碍、规则、代价，输出“走哪条通道/哪条粗轨迹”。  
**QP**：多用于**下层**——在 DP 给出的通道或参考附近，用连续变量（多项式系数等）做**凸优化**，得到满足边界、曲率、舒适度的精细轨迹。

---

## 二、DP 的职责

**场景**：纵向速度规划常在 **ST 图**上做；障碍物在 ST 中为曲线或带状禁区。  
**DP 做什么**：  
- 在离散的 (t, s) 或 (s, v) 网格上，从起点到终点做**多阶段决策**（每步选下一格或下一速度档）。  
- **代价**：时间、加速度、与障碍距离、换道代价等；可考虑动态障碍的预测轨迹。  
- **输出**：一条**粗 ST 曲线**或“可行通道”（上下界），为下层 QP 提供**约束边界**或**参考**（如 ST 曲线作为 s(t) 的参考，或通道作为 d、s 的可行域）。

**特点**：能处理**离散选择、非凸障碍、多障碍**；不直接输出平滑轨迹，但能快速给出“可行区域”与粗解。

---

## 三、QP 的职责

**输入**：DP 给出的**通道**（如 ST 上下界、参考线、车道边界）或**参考轨迹**。  
**QP 做什么**：  
- 在**连续**参数空间（多项式系数、控制点）上，最小化 jerk/加速度/偏离参考等**二次目标**。  
- **约束**：轨迹在 DP 通道内、速度/加速度/曲率边界、段间连续性等，多为**线性**（或线性化）。  
- **输出**：**平滑、可执行**的轨迹 s(t)、d(s) 及笛卡尔坐标，供控制跟踪。

**特点**：利用 DP 已处理好的“选哪条路”，只做**凸、连续**的优化，实时性好、解稳定。

---

## 四、为何分工

- **非凸 + 离散**：障碍、换道、多车道等导致**非凸、组合多**，纯 QP 难以直接解；用 DP 在离散空间搜索，把“选通道”问题解决。  
- **凸 + 连续**：在给定通道内，轨迹优化多为**凸 QP**，求解快、唯一性好；DP 负责“选”，QP 负责“做细”。  
- **实时与鲁棒**：DP 粗选 + QP 细化，计算量可控；且 DP 可快速重规划通道，QP 在通道内微调，适应动态障碍。

面试常问：“为什么不能只用 QP？”——障碍与组合导致非凸，全局 QP 无法直接处理；先 DP 定通道再 QP 是工程上成熟的分层方式（如 Apollo EM）。

---

## 小结与面试要点

**小结**：EM 类规划器上层用 DP 在离散空间选通道/粗轨迹，下层用 QP 在通道内做连续平滑优化；DP 处理非凸与离散，QP 处理凸连续，分工明确、实时可行。

**面试要点**：能说清 DP 管“选通道”、QP 管“平滑轨迹”；理解为何要分层（非凸 vs 凸、离散 vs 连续）。

---

## 记忆要点

1. **DP**：ST/车道离散空间、多阶段决策、输出通道/粗轨迹。  
2. **QP**：通道内连续优化、jerk/平滑、线性约束。  
3. **分工**：DP 选“走哪”，QP 做“怎么走细”。  
4. **原因**：非凸与组合用 DP；凸与连续用 QP。
