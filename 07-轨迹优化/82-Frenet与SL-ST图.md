# 第 82 题：Frenet 与 SL/ST 图

## 题目

Frenet 坐标系（SL）在轨迹规划中如何 used？与 ST 图的关系是什么？

---

## 一、Frenet 坐标系（SL）

**定义**：以**参考线**为基准；**s** 为沿参考线的**弧长**（纵向），**l 或 d** 为**横向偏移**（左正或右正依约定）。一点 (x, y) 对应 (s, l) 或 (s, d)：s 为参考线上最近点的弧长，l/d 为到参考线的有符号距离。

**优点**：  
- **贴合道路**：参考线即车道中心或期望路径，纵向 s 表示“沿路走了多远”，横向 d 表示“偏左/偏右”，直观。  
- **约束简单**：车道边界、车道内保持可写为 d ∈ [d_min, d_max]；限速、跟车为 s、ṡ 的约束。  
- **解耦**：纵向规划（s(t)、速度）与横向规划（d(s) 或 d(t)）可分开做，再组合；或联合优化时变量仍为 (s, d)。

**注意**：参考线曲率大时，(s, d) 与 (x, y) 的转换需考虑曲率；曲率 κ_ref 下，横向加速度等与 d、d'、d'' 及 κ_ref 有关，公式需一致。

---

## 二、SL 图与 ST 图

**SL**：横轴 s、纵轴 l（或 d），表示“在路径上哪一位置、横向偏移多少”。一条曲线 d(s) 即**路径形状**（横向几何）；若再给定 s(t)，则得到完整轨迹。  
**ST 图**：横轴 t、纵轴 s，表示“何时到路径上哪一位置”，即**纵向运动**（速度规划）。曲线斜率 = 纵向速度 ṡ。

**关系**：  
- **SL** 描述**几何**（横向相对参考线的形状）；**ST** 描述**纵向时间**（何时到哪）。  
- 完整轨迹 = **s(t) + d(s)** 或 s(t)+d(t)：ST 定“何时到哪段”，SL/d(s) 定“该段横向怎么走”；或联合 (t, s, d) 在三维中规划。  
- 障碍物：在 SL 中可表为“某 s 区间内 d 的禁区”；在 ST 中可表为“某 (t, s) 区域不可用”（动态障碍）。二者结合：先 ST 做速度规划与避障，再在对应 (s, d) 上做横向或联合优化。

---

## 三、在规划中的典型用法

- **纵向**：在 **ST** 上做 DP 或 QP，得到 s(t)、速度剖面；考虑限速、前车、红灯等。  
- **横向**：在 **s** 或 **d** 上生成 d(s)（多项式、样条），满足车道边界、曲率；或 (s, d) 上做 QP。  
- **联合**：Lattice 在 Frenet 下采样 (s, d) 终点，生成 s(t)+d(s) 候选；EM 在 ST 上 DP 再在通道内 QP，通道可在 (s, d) 或 (t, s) 下给出。

面试常问：“为什么用 Frenet 不用笛卡尔？”——道路沿参考线延伸，Frenet 下边界与约束是简单区间；纵向/横向解耦便于分层与实时优化；与高精地图车道线自然对应。

---

## 小结与面试要点

**小结**：Frenet 以参考线为基准的 (s, d) 表示；SL 描述几何、ST 描述纵向时间；规划中常用 ST 做速度、SL/d(s) 做横向或联合，再还原笛卡尔。

**面试要点**：能解释 s、d 含义；说明 SL 与 ST 各自表示什么、如何配合；Frenet 对约束与解耦的好处。

---

## 记忆要点

1. **Frenet**：s=弧长，d=横向偏移；沿参考线自然。  
2. **SL**：s-d 几何；**ST**：t-s 纵向时间。  
3. **规划**：ST 做速度与避障；d(s) 或 (s,d) 做横向/联合。  
4. **优点**：约束简单、纵横向解耦、与地图对应。
